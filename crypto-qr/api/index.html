crypto-qr
Generator GitHub

QR code API for crypto payments

Payment QR codes for crypto from a URL, for where the library does not run: an image tag, a server in any language, a bot. It is free and asks for no key. 

https://crypto-qr.toolcrypto.workers.dev/svg?chain=bitcoin&address=bc1qm6kmam774klwlh4dhmhaatd7al02m0h0hg3van&amount=0.001

Endpoints

Request Answer Type
GET /svg The code, as an SVG image. image/svg+xml
GET /png The code, as a PNG image with square modules and no logo. image/png
GET /openapi.json This API, described in OpenAPI 3.1 for the tools that read it. application/json

Both images are what the library draws for the same request. Parameters go in the query string, encoded as a URL wants them.

The payment

Parameter Value
chain Required. One of the ids listed below.
address Required. The payee. It is checked as far as its format goes: characters, length and, where there is one, checksum. The code holds it in its canonical spelling.
amount A decimal number in whole coins or tokens, such as 0.001: no exponent, no more decimals than the asset has, more than zero.
token USDT or USDC, where the chain lists it. Without it, the payment is in the chain's coin.
label Who is paid, for the payer's wallet to show.
message What the payment is for, for the payer's wallet to show.
memo Sent with the payment itself, as an exchange asks for to credit a deposit.
allowTestnet true to accept a test-network address. They are refused otherwise.

The drawing

Parameter For Value Default
size /svg Width and height in pixels, from 16 to 8192. 512
shape /svg square, rounded or dots. square
logo /svg true to draw the logo of the coin or token in the centre. false
scale /png Pixels per module, from 1 to 16. 8
margin Both Quiet zone around the code, in modules, from 0 to 20. 4
foreground Both Colour of the modules, as rgb or rrggbb. Its # may be left out: a URL has to write it %23. 000000
background Both Colour behind them, written the same way, or transparent. ffffff
ecc Both Lowest error-correction level accepted: L, M, Q or H. M, Q with a logo

The level is raised whenever a stronger one fits a code of the same size. Keep the foreground much darker than the background: scanners expect it. A PNG is as wide as the code and its margin have modules, times scale: for a larger image, or one of an exact width, ask for the SVG.

A request with nothing but an address gives the address alone on every chain, which any wallet or exchange scans. On an EVM chain, a token is in the code only along with an amount.

What is left out

What a chain's code has no place for is left out of it: an amount on Tron, a label on Ethereum. The image is still drawn, and the Payment-Warnings header names what is missing, along with the library's other warnings.

Warning Meaning
amount-not-encoded, token-not-encoded, label-not-encoded, message-not-encoded, memo-not-encoded The code does not carry that part of the request. The payer enters it.
uri-support-varies Wallets of this chain do not all read its payment links. An address alone always works.
erc20-uri-risk An EIP-681 token link starts with the token contract. A scanner that does not understand it may take the contract for the payee.
no-checksum Single-case EVM address: a typo cannot be detected.
off-curve Solana address that cannot be a wallet key: a program account, or a typo.
legacy-format Superseded address form.
testnet Test-network address, accepted with allowTestnet.

What is refused

A request that cannot be answered gets status 400 and JSON that says why, with the parameter at fault in field: 

{
"error": {
"code": "checksum",
"field": "address",
"message": "The checksum does not match: at least one character is wrong."
}
}
code field Meaning
unknown-chain chain Not one of the ids above.
unknown-parameter its name A parameter this endpoint does not have.
repeated-parameter its name A parameter given more than once.
invalid-option its name, for a switch and for scale A drawing parameter out of what it takes, or a request too long to fit in a QR code.
empty, format, length address No address, or one that is not shaped like an address of the chain.
checksum address The right shape, but its checksum does not match: almost always a typo.
wrong-chain address A valid address of another chain.
unsupported address A real address form that the library does not handle.
testnet address A test-network address, without allowTestnet.
token-contract address The address of a listed token itself, not of a wallet.
format, too-many-decimals, zero amount Not a plain decimal number, more decimals than the asset has, or zero.
unknown-token token A ticker the chain does not list.

A parameter that is not known is refused, not ignored: a misspelt amount would otherwise give a code that asks for something else than you meant. An address that is not an endpoint answers 404, and a method other than GET or HEAD 405.

From a page

Every answer has Access-Control-Allow-Origin: *, so a script of any site can read it. A code may be cached for a day: it depends on nothing but the URL.

The API runs on Cloudflare Workers and keeps no log.
