Stellar QR code generator

Paste your Stellar address to make a QR code for XLM and USDC payments, with an amount and a memo if you want them, then download it as SVG or PNG. It is free and open source, the address is checked first, and nothing you type leaves your browser.

Shape
    19 chains, with USDT and USDC where they have them: Bitcoin, Litecoin, Dogecoin, Zcash, Bitcoin Cash, XRP Ledger, Monero, Stellar, Ethereum, OP Mainnet, BNB Smart Chain, Polygon, Base, Arbitrum One, Avalanche C-Chain, Cardano, Tron, Solana, TON.

    Stellar payment codes

    What the code holds

    The code is a SEP-7 link with the address, then the amount and the memo if you type them. 

    web+stellar:pay?destination=GDPK3QG632W4BXW6VXAN5XVNYDPN5LOA33PK3QG632W4BXW6VXAN5W3G&amount=0.5&memo=INV-42&memo_type=MEMO_TEXT
    web+stellar:pay?destination=GDPK3QG632W4BXW6VXAN5XVNYDPN5LOA33PK3QG632W4BXW6VXAN5W3G&amount=0.5&asset_code=USDC&asset_issuer=GA5ZSEJYB37JRC5AVCIA5MOP4RHTM335X2KGX3IHOJAPP5RE34K4KZVN&memo=INV-42&memo_type=MEMO_TEXT

    A memo that is a whole number is sent as an id, anything else as text.

    Wallets of this chain do not all read these links. An address alone always works.

    Addresses it takes

    Accounts (G…) and muxed accounts (M…), which carry an id.

    Tokens

    Token Standard Issuer
    USDC Stellar asset GA5ZSEJYB37JRC5AVCIA5MOP4RHTM335X2KGX3IHOJAPP5RE34K4KZVN

    The address is checked

    Its characters, its length and, where the format has one, its checksum. A test-network address or the contract of a token is refused.

    Each chain's own standard

    BIP-321 for Bitcoin, EIP-681 for Ethereum, Solana Pay and the others, with the amount in the unit each one wants.

    Nothing leaves this page

    The code is made in your browser: once the page is open, it works with the network cut. No account, no tracker.

    Open source

    MIT licence, two small dependencies, tested against the vectors the standards publish. Read the code of the library and of this page.

    A fixed build

    This page runs one published version of the library and names the hash of its files: a current browser refuses any other.

    Yours to run

    Install the library from npm, or build it from its source: it makes the same codes on your machine, with no network.

    Three ways to use it

    npm

    In your code

    A typed ES module for browsers, Node, Deno, Bun and Workers. A bundler keeps only the chains you import. 

    npm install @toolcrypto/crypto-qr

import { paymentQr, stellar } from '@toolcrypto/crypto-qr'

const { svg, payment } = paymentQr({
  chain: stellar,
  address: 'GDPK3QG632W4BXW6VXAN5XVNYDPN5LOA33PK3QG632W4BXW6VXAN5W3G',
  amount: '0.5',
})
    script

    In a page, with no build step

    One file from a CDN, with everything it needs inside.

    <script type="module">
  import { paymentQr, stellar } from 'https://cdn.jsdelivr.net/npm/@toolcrypto/crypto-qr@0.1.0/dist/crypto-qr.min.js'

  const address = 'GDPK3QG632W4BXW6VXAN5XVNYDPN5LOA33PK3QG632W4BXW6VXAN5W3G'
  document.body.innerHTML = paymentQr({ chain: stellar, address }).svg
</script>
    HTTP

    From a URL
