Avalanche C-Chain QR code generator

Paste your Avalanche C-Chain address to make a QR code for AVAX, USDT and USDC payments, with an amount if you want one, then download it as SVG or PNG. It is free and open source, the address is checked first, and nothing you type leaves your browser.

Shape
    19 chains, with USDT and USDC where they have them: Bitcoin, Litecoin, Dogecoin, Zcash, Bitcoin Cash, XRP Ledger, Monero, Stellar, Ethereum, OP Mainnet, BNB Smart Chain, Polygon, Base, Arbitrum One, Avalanche C-Chain, Cardano, Tron, Solana, TON.

    Avalanche C-Chain payment codes

    What the code holds

    The code is an EIP-681 link with the address, then the amount if you type one. 

    ethereum:0xDeaDbeefdEAdbeefdEadbEEFdeadbeEFdEaDbeeF@43114?value=500000000000000000
    ethereum:0x9702230A8Ea53601f5cD2dc00fDBc13d4dF4A8c7@43114/transfer?address=0xDeaDbeefdEAdbeefdEadbEEFdeadbeEFdEaDbeeF&uint256=500000

    The link names the network by its chain id, and a token only along with an amount.

    Wallets of this chain do not all read these links. An address alone always works.

    A token link starts with the token contract: a scanner that does not understand it may take the contract for the payee.

    Addresses it takes

    Addresses of 0x and 40 hexadecimal digits. In mixed case, an address carries its EIP-55 checksum, which is checked; in a single case it has none, and the page says so.

    Tokens

    Token Standard Contract
    USDT ERC-20 0x9702230A8Ea53601f5cD2dc00fDBc13d4dF4A8c7
    USDC ERC-20 0xB97EF9Ef8734C71904D8002F8b6Bc66Dd9c48a6E

    The address is checked

    Its characters, its length and, where the format has one, its checksum. A test-network address or the contract of a token is refused.

    Each chain's own standard

    BIP-321 for Bitcoin, EIP-681 for Ethereum, Solana Pay and the others, with the amount in the unit each one wants.

    Nothing leaves this page

    The code is made in your browser: once the page is open, it works with the network cut. No account, no tracker.

    Open source

    MIT licence, two small dependencies, tested against the vectors the standards publish. Read the code of the library and of this page.

    A fixed build

    This page runs one published version of the library and names the hash of its files: a current browser refuses any other.

    Yours to run

    Install the library from npm, or build it from its source: it makes the same codes on your machine, with no network.

    Three ways to use it

    npm

    In your code

    A typed ES module for browsers, Node, Deno, Bun and Workers. A bundler keeps only the chains you import. 

    npm install @toolcrypto/crypto-qr

import { avalanche, paymentQr } from '@toolcrypto/crypto-qr'

const { svg, payment } = paymentQr({
  chain: avalanche,
  address: '0xDeaDbeefdEAdbeefdEadbEEFdeadbeEFdEaDbeeF',
  amount: '0.5',
})
    script

    In a page, with no build step

    One file from a CDN, with everything it needs inside.

    <script type="module">
  import { avalanche, paymentQr } from 'https://cdn.jsdelivr.net/npm/@toolcrypto/crypto-qr@0.1.0/dist/crypto-qr.min.js'

  const address = '0xDeaDbeefdEAdbeefdEadbEEFdeadbeEFdEaDbeeF'
  document.body.innerHTML = paymentQr({ chain: avalanche, address }).svg
</script>
    HTTP

    From a URL

    For an image tag, a server in any language, a bot. Free, with no key. The address here follows the form above, and the API's page has every parameter. 

    https://crypto-qr.toolcrypto.workers.dev/svg?chain=avalanche&address=0xDeaDbeefdEAdbeefdEadbEEFdeadbeEFdEaDbeeF&amount=0.5
